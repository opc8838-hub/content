# 从 GitHub 在线使用内容工作台

## 按需启动：GitHub Codespaces

1. 打开仓库主页，点击 **Open in GitHub Codespaces**。首次创建会安装基础图文工作台、Codex CLI、FFmpeg 和 Chromium，等待安装完成。
2. 启动后在 **Ports / 端口** 中打开 7862 对应地址。端口保持 **Private / 私有**，仅你登录 GitHub 后访问；本项目目前没有独立的网站登录系统。
3. 首次在 Codespaces 终端执行 `codex login --device-auth`，按官方提示登录你自己的 Codex 账号。远程环境与本机的登录态分开；如果设备码登录不可用，按官方文档处理。
4. 在工作台填写账号画像，查看热点、保存选题，进入对话制作文章。公众号发布配置仍使用 `wechat-publisher.yaml`，不会自动复用本机账号。
5. 下次从 [你的 Codespaces 列表](https://github.com/codespaces) 恢复**同一个**环境，工作台启动命令会再次检查和启动服务。

Codespaces 是按需环境，会因空闲或主动停止而停机。停止后恢复同一环境；删除环境会删除其中未另行备份的数据。使用额度与费用以 GitHub 账号设置为准。当前提供了启动配置，尚未创建或完成云端运行验证。

## 数据保存

- 代码、配置模板和通用能力在 Git 仓库。
- 文章、素材、画像和发布记录在该环境的 `runtime/outputs/`、`runtime/profiles/`。
- 平台会话保存在 `runtime/browser-profiles/`；Codex 认证保存在仓库内已忽略的 `.codex-runtime/`。
- 公众号实际凭证配置和 token 缓存已加入 Git 忽略规则。不要将这些目录或文件强制提交到公开仓库。
- 备份文章和画像时，使用个人受控存储；Git 上传完成不代表本机内容与云端内容已同步。

## 能力范围

在线启动配置首先安装网页、公众号文章、基础图片与浏览器工具依赖。语音转录、复杂视频处理、数据分析、去背景等附加 Python 依赖按需安装，不把“113 项能力已登记”视为每项都已完成实机验收。

浏览器平台的真实登录、二维码与发布仍需要在云端逐项验证，不能保证本机登录态可迁移。公众号官方接口还需要账号对应权限和运行环境出口 IP 白名单。

## 长期在线：独立服务器

要实现电脑关机后仍能从固定网址使用，需要持续运行的服务器、持久化数据目录、HTTPS 和访问认证。当前 FastAPI 工作台没有独立的网站访问认证，直接公开 7862 端口会暴露运营与工具接口；正式部署前应由登录网关保护整个后端。

服务器可运行同一份 Python 工作台和 Codex CLI。部署时需重新连接 Codex、配置公众号权限、数据备份以及进程自动恢复。服务器账号／托管平台确定后，再完成这一阶段；上传仓库与添加启动配置不代表已部署成长期在线网站。
